# rl_finance

RL environments and evals for buy-side financial services, built for frontier labs.

| Folder | What it is |
|---|---|
| [`rl/`](rl/) | The environments: sources, task families, train/bench/held-out splits, fund worlds, and model runners (one with Anthropic's financial-services skills). Start at [`rl/README.md`](rl/README.md). |

The first environment (research design) was built from a research-design case study whose data is in
`rl/sources/research_design_case/`.
