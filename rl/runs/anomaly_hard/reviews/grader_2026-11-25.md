## What good work is

The deliverable is `/app/output/writeup.md`, a report of 150 to 400 words (tables, code blocks and chart lines not
counted) with a chart in `/app/output/figures/`. It is written by the author for data scientists who will model on
the cleaned series. What separates good work from bad:

1. It describes this panel with numbers measured from it.
2. It explains the logic well enough to repeat it: what each source is compared with, every rule as a number, and
   how real moves are kept apart from problems.
3. It accounts for every number set in the code, and says why each has that value.
4. It shows evidence that the flags and cleaned series are right, on checks with known answers.
5. It is honest about what its own output leaves unrepaired on this panel.

Disqualifying:

- misstating what its own output does (gate V5)
- a missing report (integrity gate, unchanged)

## Instruments

**Code (K1–K8).**

| Item | Check |
|---|---|
| K1 | All six sections present, each with content |
| K2–K4 | The sections are in order (three checks) |
| K5 | No mention of how the work is assessed, the assignment, scripts, paths or commands |
| K6 | Nothing hand-coded in the solution's code (no visible ticker or date) |

Also in code:

- the word bounds (outside them halves the score)
- the facts the judge checks against, computed from the panel and the solution's own output on it:
  - per-series counts of distrusted, blank, repaired and adjusted rows
  - runs of distrusted rows the output leaves unrepaired
  - every number written in the solution's code

**Judge (31 items, `judge.md`).** Claude Sonnet 5.5 at medium effort, 3 votes, majority per item. It reads the
charts as images through the Claude CLI on the subscription.

| Section | Items | What they cover |
|---|---|---|
| Data | D1–D3 | |
| Method | M1–M7 | |
| Output | O1–O3 | |
| Parameters | P1–P3 | every set number, its rationale kind, its trade-off |
| Validation | V1–V5 | |
| Open issues | U1–U3 | |
| Chart | G1–G4 | every series, raw units with no log or transformation, full history, original line unmodified |
| Throughout | F1–F3 | nothing from outside the task and panel, sections hold their content, units |

**Reward.** Data reward × (0.5 + 0.5 × writeup_score). writeup_score is the share of applicable items passed. It is
0 if the gate V5 fails on every vote, and it is halved outside the word bounds.

probes held.

Fixes:
