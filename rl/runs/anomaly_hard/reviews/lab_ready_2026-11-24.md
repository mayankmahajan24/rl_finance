# Lab-ready: anomaly_hard (prototype, unversioned; commit after a94dad4)

**Verdict: not ready.** anomaly_hard is a prototype under `rl/experiments/`, not a registered family: no
`family.yaml`, no Harbor task package or Docker image, no split manifest, no attack-suite adapter, no approvals. The
audit script (`audit.py --family anomaly_hard`) cannot run on it ("unknown family"), so every item below was settled
by hand on train tasks. The task, grader and reference themselves pass every check that can run here; what is left is
packaging and sign-off.

## What was fixed

- **Agent code could read the answer key** (D6, E4). `grade.py` ran `score.py` as root with the task folder readable;
  a probe that finds `truth_panel.csv.gz` and `gold.json` on disk and answers with the grader's own `label_rows`
  scored **1.0** on a plain grading run (`solutions/exploit_gold_read`). Now agent code runs as `nobody`, offline, in
  its own mount namespace; the task's `tests/` folder is root-only (grader and builder); only the grader's own check
  solutions get `ORACLE_TASK`. The probe scores 0 on all 13 tasks and on 4 new ones.
- **Memory between the grader's runs** (C7, E4). `/tmp`, `/var/tmp`, `/dev/shm`, `/run/lock` were writable and kept
  between the five runs (two truncations, full, own output, truth panel), so code could count runs and game the
  stability check (`solutions/exploit_memory`: stability 0.988 -> 1.0). Each run now gets those folders empty. The
  probe scores exactly the reference.
- **The re-run on its own output was recognisable** (E4): its counts were fractional
  (`solutions/exploit_selfrun`, stability 0.988 -> 1.0). The grader now rounds that input the way raw data is
  reported. The probe scores exactly the reference.
- **Two definitions of a source's noise** (D8, found by the scale check). The builder judged a planted change
  visible against the source's own day-to-day noise; the grader and the ceiling against its noise relative to its
  sister sources, which was itself inflated by peers' low-signal days (a thin start, a too-small series). On
  low-volume companies some scored changes could not be detected by anything (ceiling 0.80 on 2 of 45 new tasks).
  Now one definition (`grade.own_noise`), measured on usable days only, is used by the builder, the grader and the
  ceiling. Ceiling 0.953 -> 0.981 on the 13 tasks (worst of 45 new tasks 0.80 -> 0.878); exact-imputation ceiling
  0.999, so the ceiling's whole gap is imputation noise. Reference 0.928 -> 0.939. One unpredicted drop explained:
  train-003 0.938 -> 0.892, a slow ramp whose leftover error the inflated noise had hidden.
- **The instruction promised a write-up grade that does not exist** (A3). Now: the write-up must exist and is read
  by a reviewer, not scored.
- **No evaluator tests** (G1). `rl/tests/test_anomaly_hard.py` (slow, about 50 s): a train task built into a scratch
  folder; the answer key passes, a paraphrase of it passes, its negation fails, do-nothing and
  distrust-everything fail, a missing write-up and a look-ahead scorer fail their gates, agent code cannot read the
  gold. `build.build_task` added so one task can be built anywhere.

No family version to bump (prototype). Every change is in `rl/runs/anomaly_hard/reviews/feedback_log.md` (#48).

## Residual risks accepted

- Outside root with namespaces the local grader cannot isolate agent code (reported as `isolation: off` in its
  output; the gold-read test skips there). The Harbor verifier will run it as `nobody`.
- The re-run on its own output drops the rows it left blank; a scorer could notice the missing thin start. Small
  (stability is 20% and the reference already scores 0.97 on it).
- The reference's safeguards are fitted to the five tuning tasks: 0.939 on the 13, 0.904 on nine new train tasks
  (worst 0.725, false alerts). It is a solvability proof, not a target for difficulty.

## Scale check (45 new train tasks, seeds 320001-320040 and 392001-392005, scratch only)

Every build succeeded (about 2 s a task). Every planted task got 8 one-day problems, 2 steps, 2 ramps and a thin start;
7 got no slow ramp and 5 only one closure (the one-lasting-change-per-company rule ran out of room). All 40 planted
fingerprints distinct. Answer key 1.0 on all 45; do-nothing 0 on all 45; ceiling 0.971 (worst 0.878); reference
0.904 on a sample of nine (worst 0.725); gold-read exploit 0.
